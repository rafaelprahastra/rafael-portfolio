# Rafael Prahastra — Personal Portfolio

Website: https://rafael-prahastra-portfolio.vercel.app

Next.js, React, TypeScript and Tailwind CSS. Node.js 24.x required.

Run npm ci, npm run dev. Production: npm run build, npm start. Deploy to Vercel using vercel.json.

Content: data/. CV: public/cv/. Regenerate CV with scripts/generate-cv.py (reportlab, pypdf).

Project diagrams are conceptual illustrations, not product screenshots. Some project descriptions are self-reported. Private bot source and production records are excluded. The private assignment report is maintained separately.
